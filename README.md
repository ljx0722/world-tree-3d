# 世界树急救队 3D 三界合作

两人同屏，沿世界树完成取雨、引水和育苗三关。首玩按约 5 分钟设计，玩家可以按自己的节奏观察和重试。

## 本机启动

1. Windows 双击 `启动游戏.cmd`。也可在本目录运行 `node server.mjs`。
2. 保持启动窗口打开，用 Chrome 或 Edge 访问 [本机试玩](http://127.0.0.1:8123/)。
3. 如需要换电脑，复制整个文件夹，并使用已安装 Node.js 的电脑启动。网页、Three.js、姿态模型及其运行依赖随文件夹提供。

## 两人怎么玩

- **机关师**按控制台上的数字键或点击按钮转动机关。天界转枝桥，人界配置两级分水闸，冥界转动根心石环。
- **搬运员**点「开启体感」，选惯用手并按提示校准。用手腕悬停对准接点或苗床，再把手腕下移一小段。收取雨珠和送入芽光使用悬停确认。点击场景或控制台也可以操作。
- **天界**把铜碗放到接通的雨门下，收下雨珠再去人界。**人界**让雨流到玉米根，带着麦皮交出的种子进入冥界。**冥界**种下种子，把芽光送入根心，观看根、干、冠逐层点亮。
- 错选后按反馈重试。人界选错二级闸时保留已接通的一级闸，冥界选错苗床时保留石环设置。重新开始可回到天界。
- 两种视角可以随时查看地形。摄像头画面在本机处理，关闭体感或全局通关后停止采集。

## 验证

- `node --test rules.test.js campaign.test.js` 检查三关规则、错误分支、奖励交接、进度重置和重复事件。
- 启动本机服务后，运行 `node --test test/browser.cjs` 验证全流程场景与控制台操作，运行 `node test/vision.cjs` 验证体感全流程和本地模型加载。浏览器测试使用 Playwright 和 Chrome，并阻止外部请求。
- 实体摄像头联排时，让双肩和惯用手手腕入镜，验证校准、悬停、下移和遮挡恢复。首次真人试玩记录从开始操作到最终结算的耗时，参考目标约 5 分钟。

## 依赖

- Three.js 0.180.0（MIT），见 `vendor/three/LICENSE`。
- MediaPipe Tasks Vision 0.10.22-rc.20250304（Apache-2.0，见 `vendor/mediapipe/LICENSE`）与 Google 提供的 Pose Landmarker Lite 模型。识别模型和 WebAssembly 随本地服务加载。

## 云端部署

以本目录为构建上下文。运行 `docker build -t world-tree-3d:1.0.0 .`，再用 `docker run --rm -p 8123:8123 world-tree-3d:1.0.0` 验证。

在 Sealos 用源码构建或导入对应容器镜像，开放容器端口 `8123` 并选择公网 HTTPS。镜像默认监听 `0.0.0.0`，公开地址由 Sealos 分配。用 HTTPS 地址打开游戏后，可以按浏览器提示授权摄像头。静态素材和姿态模型与网页同源提供。

使用 Sealos DevBox 导入源码时，选用 Node.js 环境，设置启动命令为 `sh entrypoint.sh`，开放端口 `8123`。运行依赖已随源码提供。
